SciCat Help

SciCat helps you find, inspect, and manage experimental datasets, proposals, samples, and related research data at [FACILITY NAME].

Find Data

Use the Dataset List View to search by free text, persistent identifier, run number, proposal, instrument, or acquisition date. Use the filter panel to narrow the result set further.

Inspect a Dataset

Open a dataset to review its summary, files, scientific metadata, relationships, lifecycle status, attachments, and available logbook entries. The available tabs depend on your access rights and the dataset state.

Work with Proposals

The Proposal List View provides an overview of proposal IDs, titles, instruments, abstracts, dates, and principal investigators. Opening a proposal takes you to its associated datasets.

Data Access

What you can view or edit is determined by your SciCat account and access groups. Contact your local data steward if you need access to a dataset, proposal, or instrument.

Support

For assistance, contact [SUPPORT TEAM OR EMAIL]. Include the dataset PID, proposal ID, and a short description of the issue where possible.
